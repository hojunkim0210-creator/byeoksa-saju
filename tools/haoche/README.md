# 하오체 바꾸기 도구 (업데이트 41, 2026-11-08)

벽사견 말투를 반말에서 **하오체 + '그대'**로 바꿀 때 쓴 도구다(대표님 결정·지침: `marketing/말투_하오체.md`).
사이트에는 올라가지 않는 작업용 파일이다. 업데이트 42(궁합·운세·묻기·공유 카드)·43(유료 리포트)에서 같은 기준으로 다시 쓴다.

## 쓰는 순서
단계는 `HAOCHE_STAGE` 로 고른다(41·42·43, 기본 43 = 남은 전부). 2026-11-08 업데이트 43으로 사이트 전환은 끝났다 — 새 문장은 처음부터 하오체로 쓰고, 이 도구는 혹시 남은 반말을 찾을 때 `leftover.py`로 쓴다.
```
python3 -I tools/haoche/scope.py . list      # 범위 안 문장 끝 후보 → tools/haoche/tokens.json
python3 -I tools/haoche/apply.py . dry       # 바뀔 줄 전·후 → tools/haoche/diff.txt (파일은 그대로)
python3 -I tools/haoche/leftover.py .        # 바꾼 뒤에도 따옴표 밖에 남는 반말 (0곳이 될 때까지 MANUAL 표를 채운다)
python3 -I tools/haoche/apply.py . write     # 실제로 쓴다
```
쓴 뒤에는 `npm test`(특히 `tests/e2e/tone.test.js`·`tests/static/text-preservation.test.js`)와 사람 점검으로 확인한다.

## 파일
- `scope.py` — **어디를 바꿀지**(줄 범위·문장 표 이름)와 문장 끝 후보 뽑기. 줄 번호는 41 때 기준이라, 42·43에서는 `in_scope()`의 범위와 `FREE_TABLES`를 그 단계 화면에 맞게 다시 정한다(예: 42는 `extras.js`·`shop.js` 무료 부분, 43은 `app.js` `updatePaywallContent`·`phrases.js` 리포트 표).
- `rules.py` — 확실한 말끝만 자동으로: ~었다/있다/겠다 → ~소, ~는다 → ~소, ~ㄴ다 → ~오(만든다 → 만드오), ~이다 → ~이오, 받침 그림씨 → ~소, ~하다 → ~하오, ~거라 → ~(으)시오, ~마라 → ~마시오, ~구나 → ~구려.
- `apply.py` — 손으로 정한 표(`MANUAL`), 부르는 말(네·너·네가·네게·널·넌 → 그대…, '네 기둥'은 숫자라 그대로), 문장째 바꿀 곳(`DIRECT`).
- `leftover.py` — 바꾼 결과에 남은 반말 말끝·부르는 말 목록.

## 41에서 배운 것 (같은 실수 반복하지 않게)
- **따옴표**: JS 문자열을 감싸는 따옴표는 벽사견 말이라 바꾼다. 글 속 따옴표는 안쪽이 `. ! ? …`로 끝나는 벽사견 말이고 뒤에 인용 조사(라며·하고·라는…)가 안 붙을 때만 바꾼다. 나머지(다른 사람 말 '이 정도면 됐지', 손님 속말 '내가 또 그랬구나', 주문)는 반말 그대로.
- **HTML 꾸밈 표시**(`class="impact-red"`) 속 따옴표를 대사 따옴표로 착각하지 않게 가리고 짝짓는다.
- **존댓말 빼기**: '~습니다·~ㅂ니다'만 뺀다. '아니다'까지 빼면 안 된다.
- **'ORIG.*'(원래 문장)** 은 대부분 사람에 따라 화면에 나온다 → 바꾼다. 화면에 안 나오는 `ORIG.fitWeapon`·`fitHobby`만 그대로.
- 범위 밖에 숨은 화면 글: 귀신 설명표 `GHOSTS`(app.js), `phrases.js`의 `past` 도우미. 화면을 직접 열어 보는 `tone.test.js`가 이런 걸 잡아 줬다.
- 어색해지는 말은 손으로: '젖는다' → '젖어 버리오'('젖소'로 읽힘), '갈아라' → '갈고닦으시오', '~서다' → '~라 그렇소', 이름씨+이다는 받침 뒤 '~이오'·모음 뒤 '~요'(팔자요·해요), 물음은 '?'를 살린다(거울을 들여다보겠소?).
- 손님 쪽 단추·다짐 말('문을 두드린다', '…눈을 뜬다')은 그대로.

## 42에서 더 배운 것 (43 전에 읽기)
- '~이다' 자동 규칙은 낱말 자체가 '이'로 끝나는 이름씨(사이·풀이·놀이·길이)를 '사이오'로 잘못 바꾼다 → `MANUAL`에 '사이다': '사이요'처럼 넣는다.
- 굵은 글씨 바로 뒤 말끝('…(육합)</strong>다.')은 낱말로 안 잡혀서 `TAG_END` 규칙으로 바꾼다('다' → '요', '이다' → '이오').
- 부르는 말에 '너랑·너의·너도·너한테'를 더했다. 손님이 친구에게 보내는 문구("너랑 나 궁합…")는 `PROTECT`.
- 손님이 고르는 질문 칩("돈은 언제 모여?", "내 귀인은 누구야?")은 손님 말이라 그대로(`MANUAL`에 None).
- 쌍점 앞 말끝("조심하거라:")은 낱말 끝 규칙에 안 걸리니 `DIRECT`로.
- **43 주의**: 리포트 표 `KPI_COMMENT`의 "네 가지 지표"는 숫자 '넷'이다 — 부르는 말 규칙에 '네 가지 지표'를 빼 두기. `KPI_COMMENT`·`REMEDY_FRAME`·리포트 만드는 `updatePaywallContent`에 `</strong>이다.` 꼴이 있다.

## 43에서 더 배운 것
- 쌍점·줄표 앞 말끝("세 가지 수칙이다:", "아래 1·2·3번이다 —")이 리포트에 많았다 → `scope.py`의 `END`가 `:`(뒤에 띄어쓰기·따옴표·태그)와 ` — `도 문장 끝으로 본다.
- 앞 단계에서 '건너뛰기(None)'로 정한 말(예: 따옴표 속 "느리다")이 다음 단계에서 진짜 말끝으로 나올 수 있다 → 쓰기 전에 None 낱말이 따옴표 밖에서 쓰인 곳을 한 번 훑어 보고, 그런 곳은 `DIRECT`로.
- 두 사람이 서로에게 할 한마디(궁합 상세 `NEED_WORDS`)처럼 '손님이 할 말'은 마침표로 끝나는 따옴표라도 바꾸면 안 된다 → `PROTECT`.
- 부적 효능 6줄은 원래 존댓말('~합니다')이라 그대로 두었다.

## 44에서 고친 규칙 (2026-11-09 더블체크 2-2·대표님 의견)
- '이름씨+이다 → 모음 뒤 ~요' 규칙이 '해'(한 해)·'자'(사람)에서는 '해요'·'자요'(존댓말·'잠자요')로 먼저 읽혔다 → 이 둘만 '해라오'·'자라오'. `tests/e2e/tone.test.js`가 따로 떨어진 낱말 '해요.'·'자요.'를 잡는다('팔자요'처럼 낱말 끝은 괜찮다).
- '보이다 → 보이오'는 어색하게 읽힌다(대표님) → 벽사견이 지금 보는 것은 '보이고 있소', 앞으로는 '보일 것이오', 이치는 '보이는 법이오', '~처럼 보이오'(겉보기)는 '비치오'. '좋아 보이오'는 그대로.
- 부르는 말 검사에 '네게는·네게도·너에게·너한테'를 더했다(조사가 붙어 빠져나간 '네게는'이 1곳 있었다).
